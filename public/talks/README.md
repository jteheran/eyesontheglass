## Building an Autonomous SOC as a Knowledge System

**Event:** AI Cyber Alliance  
**Date:** June 16, 2026  
**Format:** Remote  
**Slides:** [eotg-aicyberalliance-talk.pdf](./eotg-aicyberalliance-talk.pdf)  
**Recording:** Pending release  
**Event post:** https://www.linkedin.com/feed/update/urn:li:activity:7470493061886722048/

### Abstract

A live walkthrough of Eyes on the Glass — an autonomous SOC built as a knowledge system where reasoning, operational context, and memory are continuously captured so the SOC gets smarter with every shift. The talk covers ten shifts of real operational data, two findings that reshaped the architecture (the three-part context problem and process debt), and where the system is going next.
